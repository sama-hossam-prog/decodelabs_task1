# DecodeLabs Project 1 - Rule Based Chatbot 🤖

## 📌 Description
This project is a simple rule-based AI chatbot using Python.
It responds to user inputs using if-else conditions and runs in a continuous loop.

## 🚀 Features
- Handles greetings (hello, hi)
- Answers simple questions
- Runs continuously until user types exit
- Uses basic control flow logic

## 🧠 Concept Used
- if / elif / else
- while loop
- string handling

## ▶️ How to Run
```bash
python main.py
